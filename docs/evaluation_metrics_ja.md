# 評価指標

[English Version](evaluation_metrics.md)

UHVは、測定可能な指標で評価されるべきである。目的は、概念上の期待と、検証された工学データとを分けることである。

## 熱の指標

* **周囲の気温の変化：**車両から定められた距離での、運転前、運転中、運転後の気温。
* **路面温度の変化：**車両の通る経路の近くのアスファルトやコンクリートでの、赤外線または接触式の測定。
* **歩行者の快適性：**温度、湿度、気流の速度、放射熱を含む、温熱快適性の調査や指標。
* **都市規模での展開の効果：**複数の車両による、経路単位または地区単位の総合的な効果。単一のユニットから仮定するのではなく、管理されたパイロットを通じて測定する。

## ミストと水の指標

* **ミストの蒸発率：**噴霧した水のうち、地面や近くの表面に達する前に蒸発する割合。
* **水の消費量：**1時間あたりのリットル数と、走行1キロメートルあたりのリットル数。
* **路面の濡れ：**道路、歩道、車体、近くの物体における、観察またはセンサーで測定した液体の水。
* **視認性への影響：**ミストの密度と、運転者・歩行者の視認性についての、光学的または観察による評価。

## エネルギーの指標

* **発生した補助電力：**AER-Loopまたは駐車中の自然風システムからの電気出力。
* **補助電力の削減：**ファン、センサー、コントローラー、非常用システムに対する、系統、バッテリー、オルタネーターの負荷の削減。
* **走行効率への影響：**後付けのハードウェアを追加した後の、走行1キロメートルあたりの車両のエネルギー使用の変化。
* **抗力の増加：**外部モジュールや気流回収装置による、空力上の不利益。

## 運用の指標

* **保守のコスト：**人件費、部品、清掃、フィルター、水処理、停止時間。
* **信頼性：**故障と故障の間の運転時間。
* **水タンクの衛生：**清潔さ、バイオフィルムの制御、整備の間隔。
* **規制への対応状況：**対象地域での、許可、検査、遵守上のギャップ。

## 報告の形式

有用な報告には、次を含めるべきである。

* 場所と日付
* 気象条件
* 車両の種類
* 速度の範囲
* 水の流量
* 電力の消費
* 発生した補助電力
* センサーの配置
* 安全上の観察
* 生データまたは要約したデータ
* 限界と、次の試験の問い

いかなる指標も、単独で解釈してはならない。空気を冷やしても、路面を濡らしたり、水を大量に使ったり、大きな抗力を生んだりするシステムは、再設計なしには実用的でないかもしれない。
