# 後付けの実装計画

[English Version](retrofit_implementation_plan.md)

後付けの経路により、まったく新しい車両を造らなくても、UHV構想を試験できる。外部のセンターミスト冷却ユニットを、制御されたモジュールとして取り付け、独立して測定し、気流回収システムとのより深い統合の前に改良できる。

## 対象車両

後付けの対象になりうるものには、次のものが含まれる。

* バス
* 配送トラック
* タクシー
* 緊急車両
* 空港の車両
* 港湾の車両
* 建設車両
* 農業用車両
* 鉄道車両
* 船舶

これらのプラットフォームは、決まった経路や、熱にさらされる区域で運用されることが多いため、測定が容易になり、焦点を絞ったパイロット・プログラムを支えうる。

## 後付けユニットの構想

実用的な外付けユニットには、次のものが含まれうる。

* 超音波ミスト発生器
* ファンまたは気流ダクト
* 中心の噴射口
* 水タンク
* ポンプとフィルター
* 湿度センサー
* 周囲の気温センサー
* 路面温度センサー
* 水位センサー
* 安全遮断機能付きのコントローラー
* 防水の電気ボックス
* 整備しやすい取り付けフレーム

初期のユニットは、最大の冷却出力よりも、測定と安全を優先すべきである。

## 段階的な実装

### 第1段階：卓上試験

管理された屋内の条件で、ミストの生成、液滴の大きさ、蒸発率、気流との混合、水の消費、電力の消費を試験する。

### 第2段階：自転車とカートでの試験

小型のユニットを、自転車、手押し車、作業用カートに取り付け、低速での振動、気流、噴霧の方向、路面の濡れのリスクを調べる。

### 第3段階：バスと配送車両での実証

制御された外部ユニットを、バスや配送車両に取り付ける。温度、湿度、水の使用量、歩行者の曝露、視認性、保守の手間を測定する。

### 第4段階：乾燥気候での現地試験

蒸発がより有利な乾燥気候で、現地試験を行う。経路、車速、水の流量の設定、時間帯の影響を比較する。

### 第5段階：車両統合型のAER-Loop

冷却の挙動が理解された後、補助的な気流回収が、受け入れがたい抗力を生まずに、ファン、センサー、コントローラー、非常灯を支えられるかを評価する。

### 第6段階：都市の交通ネットワークへの統合

現地のデータが構想を裏づけるなら、バス路線、物流の車両群、空港の運用、港湾の運用、あるいは都市の熱ストレスのゾーンにまたがって、複数の車両を連携させる。都市規模での効果は、慎重な測定が必要であり、1台の車両の試験から仮定してはならない。

## 検証の原則

各段階は、概念上の仮定と測定された結果を分けるべきである。報告には、失敗した試験、安全上の問題、水の使用量、運用上の限界を含めるべきである。それらの結果は、責任ある開発に不可欠だからである。
