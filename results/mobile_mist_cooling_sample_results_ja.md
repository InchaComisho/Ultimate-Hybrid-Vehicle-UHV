# 移動型ミスト冷却 — 例示的なサンプル結果

[English Version](mobile_mist_cooling_sample_results.md)

> **免責事項：**これは、例示的で簡略化した冷却の推計である。
> CFDシミュレーションではない。
> 認証された、現実世界での温度低下を予測するものではない。
> 実際の冷却は、湿度、風、日射、道路の形状、
> 交通密度、液滴の大きさ、蒸発率、気流、水質、
> 保守の状態、都市の蓄熱に左右される。
> 工学的な主張を行う前に、現地試験が必要である。

## シナリオのパラメータ

| パラメータ | 値 |
|---|---|
| 車両数 | 100 |
| 車両1台あたりのミスト出力 | 5.0 L/hr |
| 運転時間 | 8.0 hr |
| 周囲の気温 | 40.0 °C |
| 相対湿度 | 25.0 % |
| 風速 | 2.0 m/s |
| 道路回廊の幅 | 30.0 m |
| 混合の高さ | 5.0 m |
| 車速 | 30.0 km/h |
| 蒸発効率 | 0.55 |
| 被覆効率 | 0.35 |
| 熱損失／希釈係数 | 0.6 |
| 最大温度低下の上限 | 5.0 °C |

## 例示的な推計

| 出力 | 値 |
|---|---|
| 1時間あたりのミスト水の総使用量 | 500.0 L/hr |
| 運転時間全体の水の総使用量 | 4000.0 L |
| 潜熱冷却の素の出力 | 340.28 kW |
| 実効の冷却出力（効率を考慮した後） | 26.20 kW |
| 回廊の推計温度低下 | 0.521 °C（上限5.0 °C） |
| 上限適用前の素の温度推計 | 0.521 °C |

**湿度に関する注記：**湿度が低い — 気化冷却の条件は有利かもしれない。

## 解釈

この代表的なシナリオは、高温で乾燥した回廊で、100台の車両が8時間運転する場合を用いている。
推計された回廊の温度低下は、概念的な例示にすぎない。
保証された、あるいは測定可能な結果として解釈してはならない。

実際の結果は、次に左右される。

- 湿度と風の条件
- 日射と都市の蓄熱
- 液滴の大きさと蒸発率
- ノズルとフィルターの保守の状態
- 水質とミネラルの含有量
- 道路の形状と交通密度
- 車両の間隔と分布

これは概念モデルである。現地試験が必要である。
